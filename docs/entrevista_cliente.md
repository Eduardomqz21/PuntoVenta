# GESTIÓN DE PROYECTOS DE SOFTWARE
## Entrevista al cliente: Expectativas del proyecto

**Proyecto:** Página web y catálogo digital para una tienda de ropa ("Novedades Ameyalli")  
**Cliente:** Propietario de una tienda de ropa

El objetivo de esta entrevista es conocer las necesidades actuales del cliente, los problemas que enfrenta en su negocio y las expectativas que tiene respecto al desarrollo de una página web con un catálogo digital de sus productos.

---

### ¿Con qué problemas cuenta actualmente?
Actualmente, el negocio tiene dificultades para mostrar de manera organizada las prendas disponibles y dar a conocer todos los productos que ofrece. La información sobre la ropa se comparte principalmente de forma presencial o mediante publicaciones y mensajes en redes sociales, por lo que puede ser complicado para los clientes consultar rápidamente los productos disponibles.

### ¿Cómo trata de resolver estos problemas?
Actualmente trata de resolverlos utilizando redes sociales, fotografías y mensajes directos para mostrar las prendas a los clientes. También proporciona información de manera personal cuando alguien pregunta por algún producto, pero este proceso requiere tiempo y no siempre permite mostrar todo el catálogo de forma ordenada.

### ¿En qué afectaría si siguen estos problemas?
Si estos problemas continúan, el negocio podría tener menor alcance hacia nuevos clientes y perder oportunidades de venta. Además, responder constantemente las mismas preguntas sobre productos, precios o disponibilidad puede consumir mucho tiempo operativo. También puede resultar más difícil para los clientes conocer todas las opciones que ofrece la tienda.

### ¿Qué espera que resuelva este proyecto?
Espera que el proyecto permita contar con una página web sencilla, clara y fácil de utilizar, donde los clientes puedan conocer la tienda, consultar un catálogo digital de la ropa disponible y armar sus propios pedidos mediante una bolsa de compras en línea. Se busca que los productos estén organizados por categorías y que la información sea fácil de administrar (idealmente mediante un sistema amigable como Excel), ayudando a mejorar la presentación del negocio y facilitar el contacto con los compradores.

### ¿Cómo visualiza su empresa/negocio/trabajo al tener este proyecto?
Visualiza su negocio con una presencia mucho más profesional en internet y con una herramienta automática que le permita mostrar sus productos de manera organizada. La página podría ayudarle a llegar a más personas, ahorrarle horas de contestar mensajes repetitivos, y servir como un catálogo dinámico que pueda actualizar de forma independiente.

---

### Conclusión
De acuerdo con las expectativas del cliente, el proyecto busca mejorar la forma en que la tienda presenta y comparte sus productos, mediante una página web que funcione como catálogo digital y punto de venta. Con ello se pretende escalar la presencia del negocio en internet, automatizar la recepción de pedidos y facilitar el proceso de comunicación con los clientes.
